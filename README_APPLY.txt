Solo Golf overlay v2

IMPORTANT:
1. Close Godot first.
2. Open a terminal in the folder that contains project.godot.
3. Run: unzip -o ~/Downloads/solo-golf-overlay-v2.zip
4. Verify with: grep "CLUB BAG" address_screen.gd
5. Reopen Godot and run the project.

This replaces address_screen.gd, ball.gd, and player.gd.
